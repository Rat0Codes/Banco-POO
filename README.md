# Sistema de Gestão Bancária — Orientação a Objetos em Python

Este repositório contém a implementação de um sistema bancário orientado a objetos em Python, demonstrando na prática os pilares fundamentais da POO: **Abstração**, **Encapsulamento**, **Herança**, **Polimorfismo** e o uso de **Métodos Especiais (Dunder Methods)**.
